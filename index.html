실습 준비 중

이론 덱을 마친 뒤 만들 실습 자리입니다. 자료가 생기면 labs/ 아래에 두고 여기에 링크를 겁니다.

  1. LAB 0공통 — 첫 subagent 하나 만들어 위임해 보기정의 파일 작성, description 라우팅, 결과 한 덩어리만 돌아오는지 확인
  2. LAB 1OpenCode — mode, permission.task, child sessionJSON·Markdown 두 방식 선언과 headless 실행에서 자식 세션 들어가 보기
  3. LAB 2Codex — 역할 TOML과 [agents] 한도스레드 띄우기·기다리기·닫기, fork_context 유무 비교
  4. LAB 3Claude Code — frontmatter, 범위 우선순위, hooks내장 agent와 커스텀 agent 호출 방식, 같은 이름 충돌 확인
  5. LAB 4패턴 — 병렬 fan-out과 반환 계약결과는 파일로, 판정은 코드로 받는 위임 흐름 만들기

위 목록은 이론 덱 구성에서 뽑은 가안이며, 실습을 만들 때 바뀔 수 있습니다.
